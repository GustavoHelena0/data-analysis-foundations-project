# Análise Exploratória de Dados de Vendas | EDA

Projeto de análise exploratória de dados desenvolvido em Python, com foco em limpeza, tratamento e visualização de dados de vendas para identificação de padrões e geração de insights.

## Funcionalidades

* Inspeção inicial do dataset
* Identificação e tratamento de valores ausentes e inconsistências
* Correção de tipos de dados e formatação de colunas
* Recálculo de valores inconsistentes na coluna de total de vendas
* Criação de variável de segmentação de clientes (VIP / NÃO VIP)
* Extração de informações temporais a partir da data de venda
* Análise exploratória por categoria, período e perfil de cliente
* Visualizações com Matplotlib e Seaborn

## Principais Análises

* Total e média de vendas
* Categoria com maior volume de vendas
* Maior venda individual
* Distribuição de vendas por mês e dia da semana
* Comparação entre clientes VIP e não VIP por categoria

## Como Executar

1. Clone o repositório:
```txt
git clone https://github.com/GustavoHelena0/data-analysis-foundations-project
```

2. Instale as dependências:
```txt
pip install -r requirements.txt
```

3. Execute o script:
```txt
python data_analysis_foundations_project.py
```
